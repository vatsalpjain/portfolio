Serif / Paper / One accent

This is a reference page that reverse-engineers the visual system of nadh.in. Every value here was taken directly from the site's stylesheet (/static/style.css), and this page is built with those same tokens. That means the page itself is the demo.

The whole system fits in about 300 lines of hand-written CSS. It has no framework, no CSS variables, no icon set, no shadows and no gradients. That restraint is the point.

00 — Foundations

Principles

  1. Typography is the interface. One serif typeface (EB Garamond) does all the work. The hierarchy comes from size and italics, not from weight or color.
  2. One accent color. #ff3300 means "this is clickable." Everything else is grayscale.
  3. Paper on a desk. A white sheet sits on a slightly gray canvas (#fff on #f6f6f6), with very generous padding (90/120px).
  4. Big body text. The root size is 23px, much larger than typical. Garamond has a small x-height, so it needs the size to read comfortably.
  5. Inverted hover. On hover, links go from orange to black, and the black button goes to orange.
  6. No decoration. No shadows, no gradients, nearly no radius (3–5px). Nothing animates except the photo crossfade.

Contrast note: #ff3300 on white is about 3.6:1. That passes WCAG AA for large text, which 23px Garamond roughly is, but not for small text. #888 and #999 meta text sit below 4.5:1. If you adopt this palette, consider #e62e00 and #767676 for strict AA.

02 — Foundations

Typography

One family: EB Garamond (a revival of Claude Garamont's 16th-century type), self-hosted as WOFF in regular and italic. The site's wordmark is a PNG image set in a geometric sans, so it's the only non-serif element. Headings use weight 500, not bold.

03 — Foundations

Spacing & layout

Spacing isn't on a strict 4/8px grid. In practice it follows a 15px rhythm (15 · 30 · 45 · 60 · 90 · 120), with 5, 10 and 20 for small adjustments.

05 — Implementation

Token file

The original site hard-codes these values. Here they are as CSS custom properties, ready to drop into a project.

:root {
  /* color */
  --c-canvas:#f6f6f6; --c-surface:#fff;
  --c-heading:#111;   --c-text:#333;
  --c-muted-1:#666;   --c-muted-2:#888; --c-muted-3:#999;
  --c-border:#ddd;    --c-subtle:#eee;  --c-code-bg:#f4f4f4;
  --c-accent:#ff3300; --c-code:#6262fb; --c-hover:#000;

  /* type */
  --font-serif:"EB Garamond", Georgia, serif;
  --fs-root:23px;  /* 20px ≤925, 26px ≥1800 */
  --fs-h1:2rem; --fs-h2:1.5rem; --fs-h3:1.3rem; --fs-h4:1.1rem;
  --fs-small:.875rem; --fs-tiny:.775rem;
  --lh-body:1.5rem; --lh-heading:1.3em; --fw-heading:500;

  /* space (15px rhythm) */
  --s-1:5px; --s-2:10px; --s-3:15px; --s-4:20px; --s-5:30px;
  --s-6:45px; --s-7:60px; --s-8:90px; --s-9:120px;

  /* shape & layout */
  --r-sm:3px; --r-md:5px;
  --container:1100px; --reading:70%; --bp:925px;
}
